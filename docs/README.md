# Youth FC Manager — 유소년 축구 클럽 통합 관리 시스템

> 유소년 축구 클럽/축구 교실 운영을 위한 올인원 관리 플랫폼

## 개요

축구교실 대표님, 코치님, 학부모님 — 모두가 만족하는 투명하고 효율적인 클럽 운영을 돕는 웹 기반 관리 시스템입니다.

원생 관리부터 출석, 회비, 훈련 기록, 학부모 소통까지 클럽 운영에 필요한 모든 기능을 하나의 플랫폼에서 제공합니다.

## 핵심 기능

| 영역 | 주요 기능 |
|------|----------|
| **원생 관리** | 기본 정보, 반 배정, 출석, 성장 기록, 증명서 발급 |
| **회비 관리** | 자동 청구, 입금 확인, 미납 알림, 환불, 수입 통계 |
| **훈련 기록** | 선수별 기술/체력 평가, 성장 그래프, 리포트 |
| **학부모 소통** | 공지사항, 1:1 메시지, 훈련 사진/영상 공유, 성장 리포트 |
| **코치 관리** | 프로필, 수업 배정, 인수인계 노트, 일정 공유 |
| **일정 관리** | 반별 시간표, 훈련 계획, 대회/친선전, 우천 취소 공지 |
| **차량 운행** | 노선/시간 관리, 탑승 인원, 도착 알림 |
| **모집/등록** | 체험수업 신청, 상담 관리, 등록 전환 |

## 대상 사용자

- **클럽 대표** — 전체 운영 현황 대시보드, 매출/출석 통계, 코치/원생 관리
- **코치** — 출석 체크, 훈련 기록, 학부모 피드백, 일정 확인
- **학부모** — 원생 정보 확인, 출석/회비 조회, 성장 리포트, 소통
- **관리자** — 시스템 설정, 권한 관리, 데이터 백업

## 기술 스택 (초안)

- **Frontend**: React (Next.js) + Tailwind CSS
- **Backend**: Django + Django REST Framework
- **Database**: PostgreSQL
- **Auth**: JWT + 소셜 로그인 (카카오, 네이버)
- **Notification**: 카카오톡 알림톡 / Push Notification
- **Storage**: AWS S3 (이미지/영상)
- **Deploy**: Docker + AWS/Vercel
