## 1. 원생 관리

### 1.1 원생 기본 정보 등록/수정/삭제

| 항목 | 설명 |
|------|------|
| **필수 입력 필드** | 이름, 생년월일, 성별, 학년, 학교, 보호자 이름, 보호자 연락처(휴대폰), 보호자와의 관계, 주소 |
| **선택 입력 필드** | 보호자 이메일, 비상연락처(제2보호자), 특이사항(알레르기, 건강상태, 복용약), 혈액형, 등록일(기본값: 오늘) |
| **기능** | 등록(생성), 조회, 수정, 삭제(soft-delete 권장) |
| **제약사항** | 삭제 시 보호자 확인 절차 필요 / 원생 상태가 "수강중"인 경우 삭제 불가 (퇴원 처리 후 삭제 가능) |
| **권한** | 대표/매니저: 전체 CRUD / 코치: 조회만 가능 |

**기대효과:** 원생 정보를 체계적으로 관리하여 수기 작성 오류를 줄이고, 보호자 연락처·특이사항을 신속히 조회할 수 있다.

### 1.2 원생 프로필 사진 / 증명사진

- **프로필 사진:** 원생 목록 및 상세 페이지에 표시되는 썸네일 이미지 (1:1 비율 권장, 최대 5MB, jpg/png/webp)
- **증명사진:** 수강증명서 발급 시 사용되는 정면 사진 (별도 저장, 고해상도)
- **업로드 방식:** drag & drop 또는 파일 선택, 촬영(모바일 앱인 경우)
- **이미지 편집:** 기본 크롭, 회전 지원 (선택)
- **저장:** 원본 + 리사이즈된 썸네일 두 가지 버전 저장

**기대효과:** 원생 식별이 용이해지고, 증명서 발급 시 사진이 필요한 경우 즉시 활용 가능하다.

### 1.3 반 배정

| 구분 | 분류 기준 |
|------|-----------|
| **유치부 (5~7세)** | 연령별 (5세, 6세, 7세), 수준별 (초급/중급) |
| **초등부 (8~13세)** | 학년별 (저학년/고학년), 수준별 (기초/심화/선수반) |
| **선수반** | 선발 기준 테스트 통과자, 대회 출전반, 별도 커리큘럼 적용 |

- **다중 반 배정:** 한 원생이 여러 반에 속할 수 있음 (예: 주중 기본반 + 주말 선수반)
- **반 이동 이력:** 반 변경 시 변경 일시, 변경 사유, 승인자 기록
- **자동 배정 규칙:** 연령과 수준 테스트 점수에 따른 자동 추천 배정 (옵션)

**기대효과:** 연령·수준별 맞춤 훈련이 가능해지고, 반 이동 이력 추적으로 원생 성장 과정을 파악할 수 있다.

### 1.4 출석 체크

| 구분 | 설명 |
|------|------|
| **출석 상태** | 정상 출석, 지각, 조퇴, 결석(사유 있음), 결석(무단), 외부 활동(대회 참가 등) |
| **출석 방식** | 강사 태블릿/모바일에서 원생 목록 체크, 학부모 앱에서 셀프 체크인(QR/비콘) |
| **출석 시간 기록** | 자동 시간 기록 (출석 체크 시각), 지각 기준 설정 가능 (예: 수업 시작 10분 초과 시 지각) |
| **출석률 통계** | 개인별/반별/월별 출석률, 지각률, 결석률 자동 집계 |
| **출석부 출력** | 월간 출석부 PDF 출력, 학부모용 출석확인서 발급 |

**기대효과:** 출석 현황을 실시간으로 파악하고, 학부모에게 투명한 출석 정보를 제공한다.

### 1.5 원생 검색/필터

- **검색어:** 이름, 보호자 이름, 연락처 일부
- **필터 조건:** 반(유치부/초등부/선수반), 연령/학년, 성별, 등록일 범위, 원생 상태(수강중/일시정지/퇴원), 출석률 범위
- **검색 결과:** 리스트형/카드형 전환, 정렬(이름순/등록일순/출석률순), 페이징 또는 무한 스크롤
- **검색 저장:** 자주 사용하는 필터 조건을 프리셋으로 저장 (권한: 대표/매니저)

**기대효과:** 많은 원생 데이터에서 원하는 정보를 빠르게 찾을 수 있다.

### 1.6 원생 상태 관리

| 상태 | 설명 | 전환 조건 |
|------|------|-----------|
| **수강중** | 정상적으로 수업 참여 중 | 신규 등록 시 기본값 |
| **일시정지** | 질병, 해외 여행 등 일시적 수업 중단 | 보호자 요청 확인 후 전환, 기간 설정 |
| **퇴원** | 수업 종료/그만둠 | 보호자 동의 완료 후 전환, 복원 불가(재등록 필요) |

- **상태 이력:** 상태 변경 일시, 변경 사유, 변경자 자동 기록
- **일시정지 만료 알림:** 설정된 기간 만료 전 관리자에게 알림
- **퇴원 처리 시:** 미납 회비 확인, 잔여 회비 환불 처리 연동, 데이터 보존(soft-delete)

**기대효과:** 원생의 수강 상태를 명확히 관리하여 허수 데이터를 줄이고, 상태 변경에 따른 후속 작업(환불, 알림)을 자동화할 수 있다.

### 1.7 증명서/확인서 발급

| 증명서 종류 | 포함 정보 |
|-------------|-----------|
| **수강증명서** | 원생 이름, 생년월일, 소속 반, 수강 기간, 발급일, 담당 코치, 클럽 직인(이미지) |
| **출석확인서** | 수강증명서 정보 + 기간별 출석일수/결석일수/출석률 |
| **훈련확인서** | 수강증명서 정보 + 훈련 참여 시간 총계 |
| **추천서** | (선수반 전용) 코치 평가, 훈련 성과, 대회 참가 이력 포함 |

- **발급 방식:** 관리자가 선택 후 PDF 생성, 원생별 발급 이력 관리
- **서명/직인:** 전자 서명 이미지 삽입, QR 코드 인증 (위변조 방지)
- **학부모 요청:** 학부모 앱에서 증명서 발급 신청 → 관리자 승인 후 다운로드

**기대효과:** 행정 업무 효율화, 학부모 만족도 향상, 증명서 위변조 방지.

## 2. 회비 관리

### 2.1 반별/원생별 월 회비 설정

| 설정 방식 | 설명 |
|-----------|------|
| **반별 기본 회비** | 각 반(유치부/초등부/선수반)에 기본 회비 금액 설정 |
| **원생별 개별 회비** | 할인(형제 할인, 장학생), 추가 옵션(개인 레슨, 대회 참가비) 반영한 개인별 금액 |
| **회비 항목 분리** | 등록금, 훈련비, 급식비, 차량비, 대회비 등 항목별 분리 설정 가능 |
| **인상/인하** | 특정 월부터 일괄/개별 적용, 인상 내역 이력 보관 |
| **유효 기간** | 회비 설정 유효기간 지정 (예: 2026년 상반기 기준) |

**기대효과:** 복잡한 회비 체계를 유연하게 설정하고, 원생별로 정확한 금액을 산정할 수 있다.

### 2.2 자동 청구/고지서 발행

- **청구 주기:** 월 1회 (매월 1일 기준), 체험수업 → 정식 등록 시 즉시 청구 가능
- **고지서 종류:** 이메일(PDF), 앱 Push, SMS 링크, 카카오톡 알림톡(템플릿)
- **고지서 내용:** 청구월, 원생명, 회비 항목별 금액, 합계, 납부 기한, 가상계좌 번호, 계좌이체 정보
- **일괄 발행:** 전체/반별 선택 후 일괄 고지서 생성 및 발송
- **예정 고지:** 3일 전 미리 고지 (선택 설정)

**기대효과:** 매월 반복되는 고지서 발행 업무를 자동화하여 행정 부담 경감.

### 2.3 입금 확인

| 방식 | 설명 |
|------|------|
| **가상계좌 매칭** | 원생별 전용 가상계좌 발급 → 입금 시 자동 매칭 (PG사 연동 필요) |
| **계좌이체 수동 확인** | 입금자명과 금액으로 관리자가 수동 매칭 |
| **카드 결제** | 온라인 PG(토스페이먼츠, KG이니시스 등) 연동, 정기 결제 |
| **현금/현장 납부** | 관리자가 직접 입금 처리 (입금일, 금액, 메모 기록) |
| **입금 확인 자동화** | 가상계좌/카드 결제 시 자동 입금 확인 → 납부 상태 업데이트 |

**기대효과:** 입금 확인 업무 시간 단축, 입금 누락 방지.

### 2.4 미납 관리

- **미납 목록:** 기간별/반별 미납 원생 목록 조회 (납부 기한 경과일 기준 정렬)
- **자동 알림:** 미납 발생 시 D-Day 기준 단계별 자동 알림 발송
  - D-Day(납부 기한 당일): 1차 안내
  - D+7: 2차 안내 (미납 수수료 안내 포함)
  - D+14: 3차 안내 (수업 제한 안내)
- **알림 채널:** 카카오톡 알림톡, SMS, 앱 Push 중 선택 가능
- **미납 현황 대시보드:** 총 미납 건수, 미납 금액 합계, 반별 미납률 그래프
- **연체율 통계:** 월별/분기별 연체율 추이 차트

**기대효과:** 미납을 조기에 발견하고 체계적으로 관리하여 회수율 향상.

### 2.5 부분 납부 / 할인 / 환불 처리

| 기능 | 설명 |
|------|------|
| **부분 납부** | 회비의 일부만 먼저 납부, 잔액은 추후 납부 (관리자가 승인) |
| **할인** | 형제 할인(X%), 조기 등록 할인(고정 금액), 장학생 할인, 추천인 할인 |
| **환불** | 퇴원/일시정지 시 잔여 일수 계산하여 환불 금액 자동 산출 |
| **환불 규칙** | 환불 기준일(예: 수업 시작 전 100%, 1주일 전 80% 등) 설정 가능 |
| **환불 내역** | 환불 요청일, 처리일, 환불 금액, 사유, 승인자 기록 |

**기대효과:** 다양한 금액 변동 상황을 체계적으로 처리하고 투명한 회계 기록을 남긴다.

### 2.6 월별/연별 수입 통계 및 그래프

- **수입 항목별:** 훈련비, 차량비, 급식비, 대회비, 기타 수입
- **기간별:** 월별, 분기별, 연별
- **비교:** 전년 동기 대비 증감률, 목표 달성률
- **시각화:** 막대 그래프, 선 그래프, 파이 차트, 누적 그래프
- **수입 예측:** 전년도 데이터 기반 예상 수입 (선택)

**기대효과:** 클럽의 재정 현황을 한눈에 파악하고, 전략적 의사결정 지원.

### 2.7 거래 내역 내보내기 (엑셀/CSV)

- **내보내기 대상:** 전체 거래 내역, 기간별, 반별, 원생별 필터링 후 내보내기
- **포함 항목:** 거래일, 원생명, 반, 회비 항목, 금액, 납부 방법, 입금자명, 상태(완납/미납/부분/환불)
- **출력 형식:** XLSX, CSV (UTF-8 BOM 인코딩, 한글 깨짐 방지)
- **자동 추출:** 정기 보고용 월간/분기별 자동 생성 및 이메일 전송 (선택)

**기대효과:** 회계 프로그램 연동 및 외부 보고 자료로 활용 가능.

## 3. 훈련 기록

### 3.1 선수별 운동 능력 평가

| 평가 항목 | 세부 내용 |
|-----------|-----------|
| **드리블** | 볼 컨트롤, 방향 전환, 속도 유지 |
| **패스** | 정확성(숏패스/롱패스), 타이밍, 파워 |
| **슈팅** | 정확성, 파워, 왼발/오른발 |
| **스피드** | 단거리 스프린트(30m), 민첩성(코스 드리블) |
| **체력** | 지구력(셔틀 런), 코어/근력 |
| **수비** | 태클, 위치 선정, 공중볼 경합 |
| **축구 지능** | 경기 이해도, 포지셔닝, 의사결정 속도 |

- **평가 방식:** 1~10점 척도 / A~E 등급 / 자유 텍스트 혼용 가능
- **평가 주기:** 매월 정기 평가, 필요시 수시 평가
- **평가자:** 담당 코치 1~2명, 복수 평가 시 평균값 산출
- **항목별 가중치:** 반별/연령별 가중치 설정 가능 (예: 유치부는 기본기 위주, 선수반은 경기력 위주)

**기대효과:** 객관적인 데이터 기반 선수 평가로 성장 정도를 정량화할 수 있다.

### 3.2 성장 추이 그래프 (시계열)

- **개인별 추이:** 각 평가 항목별 점수 변화를 선 그래프로 시각화
- **기간 선택:** 최근 1개월 / 3개월 / 6개월 / 1년 / 전체
- **비교:** 반 평균 점수 대비 비교, 동일 포지션 원생 대비 비교
- **레이더 차트:** 항목별 현재 역량을 한눈에 보여주는 레이더 차트
- **취약점 분석:** 상대적으로 낮은 점수 항목 하이라이트, 개선 권장 코멘트 표시

**기대효과:** 시간에 따른 성장 패턴을 시각적으로 파악하여 훈련 방향 설정에 활용.

### 3.3 코치 코멘트 / 평가 기록

- **평가 세션별 코멘트:** 각 평가 시 특이사항, 칭찬/보완할 점 자유 기재
- **참여도/태도 평가:** 훈련 집중도(상/중/하), 태도(적극적/보통/소극적), 협동심, 지시 이행도
- **코멘트 템플릿:** 자주 쓰는 코멘트 템플릿 저장/불러오기
- **히스토리:** 과거 평가 코멘트 전체 보관, 날짜순 정렬

**기대효과:** 숫자로 표현하기 어려운 정성적 평가를 기록하여 종합적인 선수 평가 가능.

### 3.4 월간/분기별 성장 리포트 자동 생성 (PDF)

- **리포트 구성:**
  1. 원생 기본 정보 (이름, 나이, 반, 담당 코치)
  2. 해당 기간 평가 점수 및 변화 추이
  3. 레이더 차트 + 시계열 그래프
  4. 코치 코멘트 요약
  5. 참여도/태도 평가
  6. 차기 목표/개선 권장 사항
- **생성 방식:** 버튼 클릭 시 자동 PDF 생성 (서버 사이드 렌더링), 배치 작업으로 정기 자동 생성 가능
- **리포트 디자인:** 브랜드 로고, 색상 적용 가능, A4 세로 기준

**기대효과:** 학부모에게 전문적인 피드백을 제공하고 클럽의 전문성 신뢰도 향상.

### 3.5 리포트 학부모 공유

- **공유 채널:** 앱 Push 알림 + 앱 내 PDF 뷰어, 카카오톡 링크 공유, 이메일 첨부
- **다운로드:** 학부모 앱에서 직접 PDF 다운로드
- **확인 여부:** 리포트 발송 후 학부모 확인 여부 추적 (읽음/미확인)
- **리포트 보관:** 원생별 리포트 아카이브 (학부모는 자신의 자녀만, 관리자는 전체 조회)
- **알림:** 리포트 생성 완료 시 학부모에게 즉시 알림 발송

**기대효과:** 학부모-클럽 간 정기적인 피드백 루프 형성, 학부모 만족도 제고.

## 4. 학부모 소통

### 4.1 공지사항 게시/발송

| 구분 | 대상 |
|------|------|
| **전체 공지** | 모든 학부모 (클럽 전체 운영 관련) |
| **반별 공지** | 특정 반 학부모만 (수업 일정 변경, 준비물 등) |
| **개인별 공지** | 특정 원생 학부모 (상담 요청, 개인 일정 등) |

- **공지 작성:** 제목, 내용(HTML/WYSIWYG 에디터), 첨부파일(이미지, PDF, 동영상), 발송 대상 선택
- **발송 채널:** 앱 내 공지사항 + Push 알림 (+ 연동 시 카카오톡 알림톡, 문자)
- **예약 발송:** 설정한 시간에 자동 발송
- **게시글 분류:** 일반, 긴급(상단 고정), 휴강/보강 안내, 행사 안내 등

**기대효과:** 학부모에게 중요한 정보를 신속하고 정확하게 전달.

### 4.2 공지 읽음 확인

- **읽음 처리:** 학부모가 공지 상세 페이지에 진입하면 자동 읽음 처리
- **미확인자 목록:** 공지별로 읽지 않은 학부모 목록 조회, 개별 재전송 가능
- **재알림:** 일정 시간(예: 24시간) 후에도 미확인 시 자동 재알림
- **통계:** 공지별 읽음률, 반별 읽음률 통계 제공

**기대효과:** 중요한 공지가 제대로 전달되었는지 확인 가능, 사각지대 해소.

### 4.3 1:1 메시지 (코치-학부모 간 쪽지/채팅)

- **메시지 유형:** 쪽지형(게시판식) 또는 채팅형(실시간)
- **참여자:** 코치 ↔ 학부모 (원생별로 분리), 다자간 채팅(코치 + 학부모 2인)
- **기능:** 텍스트, 이미지, 짧은 동영상 전송, 읽음 확인(1/✓✓)
- **보안:** 학부모는 자신의 자녀 코치와만 대화 가능, 코치는 담당 반 학부모와 대화 가능
- **메시지 보관:** 대화 내용 영구 보관 (삭제는 관리자만 가능)
- **알림:** 새 메시지 수신 시 Push 알림 (학부모/코치 모두)

**기대효과:** 학부모-코치 간 원활한 소통 채널 제공, 전화/문자 대체.

### 4.4 훈련 사진/영상 업로드 및 공유

- **업로드:** 수업 종료 후 코치가 태블릿/모바일로 사진 및 영상 업로드
- **자동 태깅:** 사진 속 원생 얼굴 인식 → 자동 태깅 (선택, AI 기능)
- **수동 태깅:** 업로드 후 원생 선택하여 태그, 다중 선택 가능
- **공유 범위:** 해당 반 학부모만 열람 가능, 전체 공유 옵션(클럽 홍보용)
- **다운로드:** 학부모는 태그된 자신의 자녀 사진만 다운로드 가능
- **저장 기간:** 최소 1년 보관, 자동 백업

**기대효과:** 학부모가 자녀의 훈련 모습을 실시간으로 확인할 수 있어 만족도 향상.

### 4.5 앨범 기능

- **앨범 단위:** 날짜별 앨범(×월×일 훈련), 이벤트별 앨범(체육대회, 대회, 생일파티)
- **커버 이미지:** 앨범별 대표 사진 자동/수동 설정
- **정렬:** 최신순, 오래된순, 이벤트별 필터
- **좋아요/댓글:** 학부모/코치 간 소통 기능 (앨범 내 사진별)
- **슬라이드쇼:** 전체 화면 보기, 자동 재생

**기대효과:** 훈련 사진을 주제별로 정리하여 추억 보관 및 커뮤니티 활성화.

### 4.6 학부모용 대시보드

- **내 자녀 정보:** 프로필 사진, 이름, 반, 담당 코치
- **출석 현황:** 이번 달 출석/결석/지각 일수, 출석률(%), 최근 7일 출석 상태
- **회비 현황:** 이번 달 납부 상태(미납/완납), 최근 납부 내역, 다음 납부 예정일
- **훈련 기록 요약:** 최근 평가 점수, 레이더 차트, 성장 추이(간략)
- **공지사항:** 최근 공지 5개 (미확인 배지)
- **앨범:** 내 자녀가 태그된 최근 사진 미리보기
- **1:1 메시지:** 최근 대화 요약, 안 읽은 메시지 수

**기대효과:** 학부모가 앱 하나로 자녀의 모든 활동을 한눈에 확인 가능.

### 4.7 알림

| 채널 | 용도 | 비용 |
|------|------|------|
| **카카오톡 알림톡** | 고지서 발행, 미납 안내, 공지사항, 출결 이상 | 건당 과금 (비즈메시지 계약 필요) |
| **Push 알림** | 앱 내 활동 (새 메시지, 새 사진, 리포트 생성) | 무료 (FCM/APNs) |
| **SMS** | 긴급 공지, Push 미전송 시 fallback | 건당 과금 |
| **이메일** | 정기 리포트, 고지서 PDF | 무료 (SMTP) |

- **알림 설정:** 학부모가 수신 채널별 on/off 설정 가능 (단, 긴급 공지는 강제 수신)
- **알림 템플릿:** 공지사항, 고지서, 미납, 리포트 등 유형별 템플릿 관리
- **발송 이력:** 알림 유형별 발송 이력 조회, 실패 건 재발송

**기대효과:** 학부모의 알림 수신 환경을 최적화하고 중요 정보 전달률 극대화.

| **경력** | 소속 클럽, 지도 연수, 대회 출전 경력 등 |
| **자격증** | 축구 지도자 자격증(레벨별), 기타 관련 자격증, 유효기간 관리 |

| **담당 반** | 현재 담당하는 반 목록 (다중 가능) |
| **계약 정보** | 입사일, 계약 종료일, 급여 정보(관리자만 열람), 재직 상태(재직/휴직/퇴사) |

**기대효과:** 코치 인력 정보를 중앙 관리하여 인사 데이터 정합성 유지.

### 5.2 수업 배정 / 시간표

- **수업 배정:** 반별 담당 코치 배정 (1개 반에 여러 코치 가능: 주코치+보조코치)
- **시간표 조회:** 개인별 주간/월간 시간표, 반별 시간표
- **중복 체크:** 같은 시간대 중복 배정 방지, 자동 검증
- **대타 근무:** 대타 코치 배정 및 승인 프로세스 (원래 담당 코치 요청 → 관리자 승인)
- **시간표 공유:** 코치 앱에서 본인 시간표 조회, 변경 시 Push 알림

**기대효과:** 효율적인 인력 배치와 수업 중복 방지.

### 5.3 코치 출퇴근 기록

- **출퇴근 방식:** 앱 내 체크인/체크아웃 (GPS 위치 기반 인증, 클럽 지정 위치 반경 내에서만 가능)
- **출퇴근 시간:** 자동 기록, 지각/조퇴 구분 (기준 시간 설정 가능)
- **근무 시간 집계:** 일/주/월별 총 근무 시간, 초과 근무 시간
- **근태 현황:** 월별 근태 요약 (정상/지각/조퇴/결근/휴가)
- **연장 근무:** 수동 등록 (대회 출전, 특별 훈련 등)

**기대효과:** 코치 근태 관리 투명성 확보, 급여 정산 기초 자료 제공.

### 5.4 인수인계 노트

- **작성자:** 해당 수업을 진행한 코치
- **내용:** 수업 주제, 진행 내용, 원생별 특이사항, 다음 수업 참고사항
- **인수인계 대상:** 같은 반을 담당하는 다른 코치(대타, 보조코치)
- **알림:** 인수인계 노트 작성 시 해당 반 담당 코치에게 Push 알림
- **히스토리:** 날짜별 인수인계 노트 전체 보관, 검색 가능

**기대효과:** 수업의 연속성 유지, 코치 간 정보 공유로 훈련 품질 일관성 확보.

### 5.5 내부 메모 / 게시판

- **내부 게시판:** 코치 전용 게시판 (교육 자료, 공지, 자유 게시)
- **메모:** 개인 메모 (자기 수업 기록, 아이디어), 공유 메모(특정 코치 그룹과 공유)

**기대효과:** 코치 간 정보 공유 및 내부 커뮤니케이션 채널 제공.

## 6. 일정/수업 관리

### 6.1 반별 주간/월간 시간표

- **시간표 구성:** 요일별, 시간대별 수업 슬롯
- **반별 시간표:** 각 반의 정기 수업 시간표 등록 (예: 유치부 A반 - 화/목 16:00~17:30)
- **장소 정보:** 수업 장소(실내/실외), 구장 이름, 주소
- **보강/휴강 반영:** 특정 주만 보강/휴강 등 시간표 예외 처리
- **시간표 출력:** PDF 출력, 이미지 저장, 카카오톡 공유

**기대효과:** 체계적인 수업 일정 관리로 혼선 방지.

### 6.2 훈련 계획 / 커리큘럼 작성

- **커리큘럼 구조:** 연간 → 월간 → 주간 → 회차별 계층 구조
- **회차별 계획:** 수업 목표, 주요 훈련 내용, 필요 장비, 예상 소요 시간
- **템플릿:** 자주 사용하는 훈련 세션 템플릿 저장/재사용
- **커리큘럼 진행률:** 전체 대비 진행률(%) 표시, 실제 진행 내용과 비교
- **코치 코멘트:** 계획 대비 실제 수업 후기/조정 사항 기록

**기대효과:** 체계적인 훈련 계획 수립 및 실행 관리, 훈련의 질 향상.

### 6.3 대회/친선전 일정 등록 및 공유

- **일정 등록:** 대회명, 주최, 일시, 장소, 참가 반/원생, 준비물, 비용
- **대진표:** 대회 대진표 업로드/링크 (이미지 또는 외부 링크)
- **참가자 관리:** 참가 원생 명단 관리, 불참 사유 기록
- **결과 기록:** 대회 결과(승/패/무), 득점, MVP 기록
- **일정 공유:** 학부모 앱에 자동 표시, 캘린더 내보내기(iCal)

**기대효과:** 대회 참가 관련 정보를 체계적으로 관리하고 학부모와 공유.

### 6.4 우천/돌발 상황 취소/변경 공지 (일괄 발송)

- **취소/변경 등록:** 해당 일정 선택 후 취소/변경 사유, 대체 일정 입력
- **일괄 발송:** 대상 반 학부모 전체에게 즉시 알림 발송
- **발송 채널:** Push + 카카오톡 알림톡(긴급), SMS(최우선)
- **학부모 확인:** 공지 확인 버튼, 미확인자 재발송
- **보강 일정:** 취소된 수업의 보강 일정 자동 제안 (학부모 투표 기능: 선택)

**기대효과:** 돌발 상황에 신속 대응, 학부모 혼란 최소화.

### 6.5 캘린더 연동

- **내부 캘린더:** 앱 내 통합 캘린더 (수업, 대회, 휴관일, 행사)
- **외부 연동:** Google Calendar, Apple Calendar, Outlook 등 iCal 형식 구독 가능
- **필터:** 반별, 일정 유형별(수업/대회/행사 등) 필터
- **캘린더 공유:** 학부모가 자신의 캘린더에 클럽 일정 추가 가능

**기대효과:** 학부모/코치 개인의 일정 관리 도구와 연동하여 편의성 증대.

## 7. 차량 운행 관리 (선택)

> 이 영역은 선택 사항입니다. 차량 운행 서비스를 제공하는 클럽만 구현합니다.

### 7.1 운행 노선 및 시간 등록

| 항목 | 설명 |
|------|------|
| **노선명** | 예: "서초동 노선", "강남역 노선" |
| **정류장** | 노선별 정류장 목록 (주소, 도착 예정 시간) |
| **운행 시간** | 등원 시간대, 하원 시간대 각각 설정 |
| **차량 정보** | 차량 번호, 차종, 좌석 수, 운전자 정보 |
| **요금** | 노선별 월 요금 (회비 항목과 연동) |

**기대효과:** 차량 운행 정보를 체계적으로 등록/관리.

### 7.2 탑승 원생 명단 관리

- **노선별 탑승객:** 각 노선/시간대별 탑승 원생 배정
- **탑승 변경:** 일시적 탑승 변경/취소 (학부모 앱에서 신청 → 관리자 승인)
- **미탑승 관리:** 등원 차량에 탑승하지 않은 경우 학부모/관리자 알림
- **하차 확인:** 하원 시 하차 확인 (어플 체크 또는 운전자 확인)

**기대효과:** 차량 탑승 현황 실시간 파악, 안전 관리 강화.

### 7.3 차량 출발/도착 알림 (학부모용)

- **출발 알림:** 차량 출발 시 Push 알림 (예상 도착 시간 포함)
- **도착 알림:** 정류장 도착 시 Push 알림 (5분 전/도착 즉시)
- **실시간 위치:** 학부모 앱에서 차량 실시간 위치 지도 조회 (선택)
- **지연 알림:** 예상 시간 대비 10분 이상 지연 시 자동 알림

**기대효과:** 학부모가 차량 도착 시간을 정확히 파악하여 불안감 해소.

### 7.4 운행 기록

- **일일 운행 기록:** 출발 시간, 도착 시간, 탑승 인원, 특이사항
- **월간 운행 통계:** 총 운행 일수, 총 탑승 인원, 지연 횟수
- **운행 일지 출력:** 월간 운행 기록 PDF 출력

**기대효과:** 차량 운행 이력 데이터 축적 및 안전 관리 근거 확보.

## 8. 신규 원생 모집

### 8.1 체험수업 신청 폼

| 구분 | 설명 |
|------|------|
| **공개 모드** | 클럽 웹사이트/랜딩페이지에 신청 폼 노출, 누구나 신청 가능 |
| **비공개 모드** | 관리자가 생성한 링크를 통해서만 신청 가능 (지인 추천, 특별 모집) |
| **신청 폼 항목** | 원생 이름, 생년월일, 성별, 학년, 보호자명, 연락처, 희망 체험 일정, 전달사항 |
| **자동 응답** | 신청 완료 시 보호자에게 확인 문자/카톡 자동 발송 |
| **신청 현황** | 관리자 페이지에서 신청 목록 조회, 처리 상태(미확인/확인/체험완료/등록전환) 관리 |

**기대효과:** 체험수업 신청 프로세스 자동화로 모집 효율 향상.

### 8.2 체험수업 일정 관리

- **체험 일정 등록:** 체험수업 가능한 날짜/시간대 설정
- **인원 제한:** 회차별 최대 인원 설정 (초과 시 대기자 등록)
- **일정 표시:** 신청 폼에 체험 가능 일정 자동 표시 (신청자가 선택)
- **체험수업 진행:** 출석 체크, 간단한 피드백 기록 (코치용)

**기대효과:** 체험수업 일정을 체계적으로 관리하여 중복/혼선 방지.

### 8.3 상담 기록 / 이력

- **상담 유형:** 방문 상담, 전화 상담, 채팅 상담, 체험수업 후 피드백
- **상담 내용:** 상담 일시, 상담자(코치/매니저), 상담 내용, 후속 조치
- **관심도 평가:** 관심도(상/중/하), 등록 예상 시기, 추가 연락 일정
- **상담 이력 조회:** 보호자명/연락처로 검색, 과거 상담 내역 전체 조회

**기대효과:** 신규 문의자의 관심도를 추적하고 맞춤형 후속 조치 가능.

### 8.4 등록 전환 프로세스

1. 체험수업 완료 → 등록 안내 발송 (자동 템플릿)
2. 학부모가 등록 의사 표시 (앱/링크에서)
3. 관리자가 등록 정보 입력 (반 배정, 회비 설정, 첫 수업일 지정)
4. 등록 완료 → 환영 메시지 자동 발송 + 학부모 앱 계정 생성 안내
5. 첫 수업 전 준비사항 안내 (준비물, 시간표, 차량 정보)

- **전환율 통계:** 체험수업 대비 등록 전환율, 기간별 전환율 추이

**기대효과:** 신규 원생 등록 프로세스를 표준화하고 전환율 모니터링 가능.

### 8.5 문의 관리

- **문의 채널:** 앱 내 문의, 웹사이트 문의, 전화 문의 기록 수동 입력
- **문의 유형:** 등록 문의, 회비 문의, 수업 문의, 기타
- **답변 처리:** 답변 완료 시 문의자에게 자동 알림, 답변 템플릿 사용 가능
- **처리 상태:** 접수/처리중/답변완료/보류
- **자주 묻는 질문(FAQ):** 관리자가 FAQ 등록/수정, 앱 또는 웹에 노출

**기대효과:** 문의 응대 품질 향상, 단순 반복 문의는 FAQ로 대체.
