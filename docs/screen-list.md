## 📐 화면 설계 참고 포인트

### 대표 (Admin) 화면
- **큰 글씨 + 큰 버튼** (기술에 익숙하지 않은 사용자 배려)
- 최소 클릭으로 필요한 정보에 도달
- 카드형 UI로 정보 밀도 낮춤

### 매니저 (Manager) 화면
- **테이블 뷰 + 엑셀 내보내기** 필수
- 일괄 작업 (선택 → 적용) UI 최적화
- 데이터 정합성 확인용 변경 로그 표시

### 코치 (Coach) 화면
- **모바일 퍼스트** (현장에서 스마트폰 사용)
- 큰 터치 영역, 간결한 입력 (별점/토글/음성)
- 오프라인 대응 (필드에서 인터넷 약한 상황 고려)

### 학부모 (Parent) 화면
- **읽기 전용 중심** (수정 권한 최소화)
- 시각적 그래프/차트로 정보 전달
- 푸시 알림 → 바로 확인하는 딥링크 구조
